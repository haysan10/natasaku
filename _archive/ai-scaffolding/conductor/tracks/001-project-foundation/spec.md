# Track 001 — Project Foundation Spec

## Goal

Create the Android project foundation for NataSaku using Kotlin, Jetpack Compose, Material Design 3, Navigation Compose, Room, DataStore, Coroutines, and a clean package structure.

## Scope

- Project structure.
- MainActivity.
- App theme shell.
- Navigation shell.
- Base package layout.
- Core utilities.
- Initial dependency setup.
- Basic build verification.

## Requirements

1. App builds successfully.
2. Uses Kotlin.
3. Uses Jetpack Compose.
4. Uses Material Design 3.
5. Has package structure for data, domain, and presentation.
6. Has placeholder navigation routes.
7. Has no login/backend/cloud dependency.
8. Has no internet-required feature.
9. Includes base test setup.

## Acceptance Criteria

- App launches to placeholder Splash route.
- Project compiles.
- Package structure exists.
- Theme wrapper exists.
- Navigation host exists.
- No forbidden dependencies are added.

## Out of Scope

- Full UI implementation.
- Database schema details.
- Budget calculation implementation.
- Export features.
