# Contributing to NataSaku

Thank you for your interest in contributing to NataSaku! 

## Code of Conduct
Please read and follow our [Code of Conduct](CODE_OF_CONDUCT.md) to keep this community welcoming.

## How to Contribute
1. Fork the repository.
2. Create a feature branch: `git checkout -b feature/your-feature-name`.
3. Make sure all tests pass: `flutter test` inside `natasaku_flutter/`.
4. Submit a Pull Request.
