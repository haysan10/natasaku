# Contributing to NataSaku

Terima kasih sudah ingin berkontribusi.

## Alur Kontribusi

1. Fork repository ini.
2. Buat branch dari `main` dengan nama yang jelas.
3. Lakukan perubahan yang fokus.
4. Tambahkan atau update test jika ada perubahan perilaku.
5. Buka Pull Request dengan ringkasan yang jelas.

## Format Branch

- `feat/<nama-singkat>`
- `fix/<nama-singkat>`
- `chore/<nama-singkat>`
- `docs/<nama-singkat>`

## Checklist Pull Request

- Build lokal berhasil.
- Test relevan lulus.
- Tidak ada file sensitif yang ikut commit.
- Dokumentasi diperbarui jika perlu.
