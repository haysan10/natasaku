# Track 007 — Transaction History Spec

## Goal

Implement Transaction History screen with grouped transactions, search, category filter, total filtered spending, edit, and delete.

## Requirements

1. Show transaction list grouped by date.
2. Show search field.
3. Show category filter chips.
4. Show total spending for filtered result.
5. Allow edit transaction.
6. Allow delete transaction with confirmation.
7. Soft delete transaction.
8. Recalculate dashboard/report after edit/delete.

## Acceptance Criteria

- List grouping is correct.
- Search works.
- Filter works.
- Total filtered spending accurate.
- Edit updates data.
- Delete removes from default list.
- Empty state shown when no data.

## Out of Scope

- Import transactions.
- Bank sync.
