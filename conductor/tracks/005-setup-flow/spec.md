# Track 005 — Setup Flow Spec

## Goal

Implement first-time setup flow from Welcome through Review Budget.

## Screens

1. Welcome.
2. Onboarding.
3. Setup Period.
4. Setup Income.
5. Setup Fixed Expense.
6. Setup Saving Target.
7. Review Budget.

## Requirements

1. User can complete setup without internet.
2. User can select period type.
3. User can add income sources.
4. User can add fixed expenses.
5. User can add or skip saving target.
6. User can review calculated budget.
7. User can save active budget period.
8. Back navigation works within setup.
9. Setup completion navigates to Home.

## Acceptance Criteria

- Setup persists to Room/DataStore.
- Review Budget shows correct numbers.
- User cannot continue with invalid required data.
- Copywriting is friendly.
- No login or account step exists.

## Out of Scope

- Editing existing budget after setup.
- Advanced templates.
