# Track 002 — Design System Spec

## Goal

Implement NataSaku visual foundation using Material Design 3 theme, color tokens, typography, spacing, shape system, and reusable component styling.

## Scope

- Light color scheme.
- Dark color scheme.
- Typography.
- Shape tokens.
- Dimension tokens.
- Shared components.
- Status colors.
- Previews.

## Requirements

1. Define NataSaku light and dark Material color schemes.
2. Define typography scale.
3. Define shape system.
4. Define shared dimensions.
5. Create reusable base components.
6. Avoid hardcoded colors in screens.
7. Support dark mode.
8. Status colors must include safe/warning/overbudget variants.

## Acceptance Criteria

- Theme compiles.
- Light and dark previews work.
- Components use MaterialTheme.
- Status chips readable in both themes.
- No screen-specific random colors.

## Out of Scope

- Full screen implementation.
- Business logic.
- Database.
