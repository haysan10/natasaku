# Track 006 — Home Dashboard Spec

## Goal

Implement the main Home Dashboard showing daily allowance, spent today, remaining today, status, monthly progress, insight, and FAB to add expense.

## Requirements

1. Show greeting.
2. Show active period.
3. Show daily allowance hero card.
4. Show spent today.
5. Show remaining today.
6. Show status: Aman/Waspada/Melewati Batas.
7. Show monthly progress.
8. Show category summary.
9. Show insight.
10. Add expense FAB opens bottom sheet.
11. Saving expense updates dashboard.
12. Overbudget dialog appears when needed.

## Acceptance Criteria

- Dashboard answers “hari ini aman atau tidak?” quickly.
- UI remains uncluttered.
- Add expense can be completed fast.
- Status is not color-only.
- Works offline.
- Light/dark mode works.

## Out of Scope

- Advanced charts.
- Online sync.
