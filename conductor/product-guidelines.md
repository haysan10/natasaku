# conductor/product-guidelines.md — NataSaku Product Guidelines

## Brand Personality

NataSaku should feel:

- Helpful.
- Calm.
- Friendly.
- Professional.
- Private.
- Non-judgmental.
- Easy to understand.
- Like a friendly personal finance manager.

---

## Voice and Tone

Use tone that is:

- Supportive.
- Clear.
- Practical.
- Gentle.
- Encouraging.
- Neutral when showing problems.

Avoid tone that is:

- Scolding.
- Fear-based.
- Overly formal.
- Too childish.
- Corporate-bank rigid.
- Shame-based.

---

## Core Copy Rules

1. Use Indonesian UI copy.
2. Use “kamu” consistently.
3. Keep button labels action-oriented.
4. Keep mobile copy short.
5. Put the most important information first.
6. Avoid financial jargon unless explained.
7. Avoid blaming user.
8. Every error should offer a recovery path.
9. Every warning should sound helpful, not punitive.
10. Use consistent terminology.

## Forbidden Copy

Never use:

- Kamu boros.
- Budget gagal.
- Kamu salah.
- Tidak disiplin.
- Pengeluaranmu buruk.
- Keuanganmu kacau.
- Harusnya kamu tidak belanja.
- Budget kamu hancur.

Replace with:

- Jatah hari ini terlewati.
- Budget perlu disesuaikan.
- Pengeluaran bulan ini lebih tinggi dari rencana.
- Kamu bisa menyesuaikan nominal agar lebih nyaman.

## Error Messages

### Invalid Amount

> Nominal belum valid. Masukkan nominal lebih dari Rp0, ya.

### Invalid Date

> Tanggal akhir perlu setelah tanggal mulai.

### Export Failed

> File belum berhasil dibuat. Coba lagi atau pilih lokasi penyimpanan lain.

### Restore Failed

> File backup tidak bisa dibaca. Pastikan file berasal dari NataSaku.

### Insufficient Flexible Fund

> Pengeluaran tetap dan tabungan lebih besar dari penghasilan. Kamu bisa menyesuaikan nominal agar jatah harian tersedia.

## UI Formatting Rules

### Currency

Use Indonesian Rupiah:
- Rp0
- Rp60.000
- Rp1.500.000

No decimal needed.

### Date

Use Indonesian-friendly date:
- 7 Mei 2026
- 1–31 Mei 2026

### Buttons

Use action verbs:
- Mulai
- Lanjut
- Simpan
- Catat
- Download
- Export
- Bagikan
- Buka File

---

## Review Checklist

Before approving UI copy:

- [ ] Is it Indonesian?
- [ ] Is it short enough for mobile?
- [ ] Is it friendly?
- [ ] Is it non-judgmental?
- [ ] Does it use consistent terms?
- [ ] Does the error explain recovery?
- [ ] Does the warning avoid blame?
- [ ] Does the CTA clearly say what happens next?
